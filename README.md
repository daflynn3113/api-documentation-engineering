# API Documentation Engineering

A practical learning and portfolio repository focused on API documentation, technical communication, and documentation engineering.

## About This Repository

This repository documents my progression from traditional technical writing to API documentation engineering.

It contains practical exercises, documentation examples, API specifications, testing resources, and portfolio projects developed while learning industry-standard documentation tools and workflows.

## Learning Objectives

- Understand HTTP fundamentals and REST API architecture.
- Work with JSON and XML data formats.
- Test APIs using Postman.
- Create and validate OpenAPI specifications.
- Write clear, task-oriented API documentation.
- Use Git and GitHub for version control.
- Explore documentation automation and documentation-as-code workflows.
